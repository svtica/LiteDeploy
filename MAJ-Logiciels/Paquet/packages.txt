#  - A running process is closed (forced) before the package is upgraded.
#  - Label: name shown in the panel and in the messages to the user (default: the Id).
#  - DisplayName regex: finds the installed version in the registry (panel, verify-winget-upgrade.ps1).
#    Group 1, when present, is used as the version instead of DisplayVersion. No "|" in the regex.
